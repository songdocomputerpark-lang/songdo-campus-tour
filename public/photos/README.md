# 사진 넣는 방법

이 폴더(`public/photos/`)에 **시설 ID 이름의 폴더**를 만들고 사진을 넣으면, 해당 시설의 상세 안내와 추천 투어에 사진이 표시됩니다.

## 규칙

1. 폴더 이름은 아래 표의 **시설 ID** 와 정확히 같아야 합니다. 예) `public/photos/main-2f-c1-1/`
2. 건물 전경 사진은 `building-<건물ID>` 폴더에 넣습니다. 예) `public/photos/building-main/`
   건물 ID: `main`(본관동), `new`(신관동), `science`(과학관동), `library`(도서관동), `gym`(체육관동), `dining`(급식관동), `restroom`(화장실동)
3. 형식: `jpg` `jpeg` `png` `webp` `avif`. 파일 이름 순서(숫자 순)대로 표시됩니다 (`01.jpg`, `02.jpg` …).
4. 권장 크기: 가로 1600px 이하, 파일당 300KB 안팎 (스마트폰에서 빠르게 열리도록).
5. 사진 설명(선택): 같은 폴더에 `captions.json` 을 만들고 `{ "01.jpg": "사진 설명" }` 형식으로 적습니다.
6. 터미널에서 `npm run photos` 를 실행하면 `public/content/photos.json` 이 갱신됩니다. `npm run dev` / `npm run build` 는 자동으로 실행합니다.
7. 학생 얼굴이 식별되는 사진은 학교 개인정보 보호 지침과 초상권 동의를 확인한 뒤에만 사용하세요.
